Coordenadas homogêneas

A translação não é linear: ela tira a origem do lugar, e nenhuma matriz 2×2 consegue fazer isso. O truque é ganhar uma coordenada extra w: o ponto (x ; y) vira [x, y, 1]. Com isso, translação, rotação, reflexão… viram todas uma multiplicação por uma matriz 3×3 (ou 4×4 no 3D). Esta aba mostra o código Java que faz essa conversão em Transformations.java.
